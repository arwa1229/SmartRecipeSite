# smartrecipe.co site logo

Vector recreation of the logo used on smartrecipe.co: the wide-tracked
"SMART RECIP" wordmark (with the crossbar-less Λ), the three-bar "E" mark, and the
"IT COMPANY" tagline. Letters are drawn as paths, so no font is needed.

| File | Use |
|------|-----|
| `smartrecipe-logo-dark.svg` | On dark backgrounds (as on the site) — transparent |
| `smartrecipe-logo-dark-bg.svg` | Same, with the dark background included |
| `smartrecipe-logo-light.svg` | On white / light backgrounds |
| `*-notagline.svg` | Without "IT COMPANY" (small sizes, headers) |
| `smartrecipe-icon.svg` / `-light.svg` | App icon / social avatar |
| `smartrecipe-mark-transparent.svg` | "E" mark only |
| `png/` | High-res PNG exports of all of the above |

Colors: teal `#5CC4A9` (light backgrounds: `#1F9E80`), white `#F3F6F5`,
ink `#0E1513`, background `#0B1110`.

Regenerate with `python3 build.py`.
