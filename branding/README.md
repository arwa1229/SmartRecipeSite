# Smart Recipe — Brand Assets

Modern, minimalist logo for **Smart Recipe** (IT company).

## Concept

A minimal bowl with **"smart steam"** — the steam rising from the bowl is drawn
as a Wi‑Fi–style connectivity signal. One clean mark that says both
*cooking/recipes* and *technology*.

## Files

| File | Use |
|------|-----|
| `logo-horizontal.svg` | Primary logo — website header, documents, light backgrounds |
| `logo-horizontal-dark.svg` | Primary logo for dark backgrounds |
| `logo-stacked.svg` | Vertical lockup — social profiles, splash screens |
| `logo-icon.svg` | Icon mark only, light backgrounds |
| `logo-icon-dark.svg` | Icon mark only, dark backgrounds |
| `logo-app-icon.svg` | App icon / favicon — gradient rounded square |
| `logo-showcase.html` | Preview page showing all variants |

## Colors

| Color | Hex | Role |
|-------|-----|------|
| Emerald | `#10B981` | Primary brand / gradient start |
| Teal | `#0D9488` | Gradient end |
| Ink | `#0F172A` | Text and bowl mark |
| Slate | `#64748B` | Secondary text |

On dark backgrounds the gradient brightens to `#34D399 → #2DD4BF` and the mark
switches to `#F8FAFC`.

## Typography

Wordmark uses **Inter** (Bold 700, tight letter-spacing), falling back to the
system sans-serif stack. Tagline "IT SOLUTIONS" uses Inter Medium with wide
letter-spacing.

## Usage notes

- Keep clear space around the logo of at least the height of the bowl mark's foot.
- Minimum size: 24 px height for the icon, 120 px width for the horizontal logo.
- Don't recolor, outline, distort, or add effects to the mark.
